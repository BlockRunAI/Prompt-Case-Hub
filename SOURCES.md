# Integrated sources

Prompt-Case-Hub is a **curation + format layer**. It does not claim authorship of
the prompts it normalizes. Every integrated case carries a `source` block (see
[FORMAT.md](./FORMAT.md)) pointing back to one of the repositories below. Before
redistributing any case content, check the upstream license.

> Star counts are approximate, captured at integration time, and only indicate
> popularity — they are not an endorsement.

## Image / video generation

### BlockRunAI/Claude-Code-GPT-IMAGE2-SeeDance-BlockRun
- **URL**: https://github.com/BlockRunAI/Claude-Code-GPT-IMAGE2-SeeDance-BlockRun
- **Focus**: One-line image/video generation cases (gpt-image-2, Seedance) runnable
  via Claude Code with x402 USDC payment on Base.
- **Role here**: The seed library this hub grew out of; its case library is the
  first import target.
- **License**: See upstream repository.

### jamez-bondos/awesome-gpt4o-images
- **URL**: https://github.com/jamez-bondos/awesome-gpt4o-images
- **Focus**: Curated collection of images and prompts generated by GPT-4o /
  gpt-image-1, with previews.
- **Role here**: Primary source of high-quality, preview-backed image cases.
- **License**: See upstream repository.

## General / text prompts

### f/prompts.chat  (f.k.a. Awesome ChatGPT Prompts)
- **URL**: https://github.com/f/prompts.chat
- **Focus**: The classic community collection of ChatGPT prompts. Free and open source.
- **Role here**: Source of general-purpose text cases (act-as / role prompts).
- **License**: See upstream repository (historically CC0).

### dair-ai/Prompt-Engineering-Guide
- **URL**: https://github.com/dair-ai/Prompt-Engineering-Guide
- **Focus**: Guides, papers, lessons and resources for prompt/context engineering.
- **Role here**: Reference patterns and technique-oriented text cases.
- **License**: See upstream repository (MIT for code, content varies).

### linexjlin/GPTs
- **URL**: https://github.com/linexjlin/GPTs
- **Focus**: System prompts of public GPTs.
- **Role here**: Source of system-prompt / instruction-style text cases.
- **License**: See upstream repository.

### EmbraceAGI/awesome-chatgpt-zh
- **URL**: https://github.com/EmbraceAGI/awesome-chatgpt-zh
- **Focus**: Chinese-language ChatGPT guide and curated prompt list.
- **Role here**: Source of Chinese-language text cases.
- **License**: See upstream repository.

## Adding a source

Open a PR that:
1. Adds the repository to this file with URL, focus, role, and license.
2. Adds at least one correctly-formatted, attributed case under `cases/`.
3. Registers each new case in `cases/index.json`.

A source whose license forbids redistribution can still be **linked and indexed**
(metadata + link only) without copying its prompt text.
